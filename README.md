## The joke

> I gave my AI assistant full control of my inbox so I could finally relax — now I relax while it confidently apologizes to strangers at superhuman speed.

## How it works

`main.ts` is a small deterministic program (Node 22, no network, no randomness).
It writes the one-line joke above — 152 characters, a single line — to
`/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt
```
